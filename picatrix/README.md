# Picatrix (غاية الحكيم)

**Author:** Maslama al-Majriti (attributed, d. ~1008 CE)
**Original language:** Arabic
**Original period:** ~10th-11th century
**Status:** Public domain (medieval work)
**Public translation status:** Coming soon

## Description

The *Picatrix* is the Latin title of *Ghayat al-Hakim* ("The Aim of the Wise"), an encyclopedic Arabic grimoire covering astrology, talismanic magic, planetary invocations, and the lore of lunar mansions. It is the single most important text for the transmission of Arabic astral magic into the Latin West.
